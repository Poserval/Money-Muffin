📱 Установить приложение

🤖 Для Android

Способ 1 (APK):

  1. Скачайте файл MoneyMuffin.apk
  2. Разрешите установку из неизвестных источников
  3. Запустите файл и установите приложение

Способ 2 (PWA):

  1. В Chrome нажмите "⋮" (меню)
  2. Выберите "Добавить на главный экран"
  3. Подтвердите установку

🍎 Для iPhone

  1. Откройте приложение в Safari
  2. Нажмите кнопку "Поделиться" 📤
  3. Выберите "На экран «Домой»"
  4. Нажмите "Добавить" в правом верхнем углу

Приложение установится на главный экран и будет работать как обычное приложение!

💻 Для компьютеров

Chrome/Edge:

  1. Нажмите на значок "Установить" в адресной строке
  2. Подтвердите установку

Приложение появится в меню "Пуск" и будет работать в отдельном окне
